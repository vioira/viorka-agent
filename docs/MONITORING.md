# 节点主机监控

Agent 在已认证的出站 WSS 中发送 `node.metrics`，不开放新的端口、不执行 Shell、不修改代理服务。当前采集目标是 Linux amd64/arm64，读取当前主机命名空间的 `/proc` 和根文件系统 `statfs`；不将容器 cgroup 配额误称为主机总量。非 Linux 返回 `unsupported_platform`，不会返回伪造的零指标。

## 指标与语义

- CPU：`/proc/stat` 聚合 CPU 前八项的差值（不再次累加 guest）；idle 与 iowait 计为空闲。显示全机 0–100% 使用率和逻辑 CPU 数。
- 内存：`MemTotal - MemAvailable` 为已用量，另报可用量、总量、Swap 已用/总量。缺少 `MemAvailable` 不猜测替代值。
- 负载与运行时长：`/proc/loadavg` 的 1/5/15 分钟负载，以及 `/proc/uptime`。
- 磁盘：仅根文件系统 `/` 的总量、已用量、普通用户可用量；保留块使已用加可用不一定等于总量。不扫描文件树，不枚举远端挂载。
- 网络：`/proc/net/dev` 每个非回环网卡的累计 RX/TX 字节，以及两个成功采样间的字节/秒速率。首次采样、网卡新增、计数器倒退、采集失败后的恢复，以及大于 600 秒的间隔不产生速率。虚拟网卡可能重复记录同一业务流量，合计仅用于观察主机接口活动；不是今日、月度、代理用户用量或服务商计费。

CPU 首次采样或计数器倒退也只报告 CPU 数，等待下一次有效差值。每个采集组单独报告 `*_unavailable`，不把未知量写为 0。错误只使用固定代码，不发送本地路径或系统错误文本。

## 配置和资源上限

本地配置增加可选 `metrics_seconds`：默认 30，允许 10–300 秒，0 等同默认。指标周期独立于握手协商的心跳周期。每个内核文件最多读 256 KiB，最多 64 个非回环网卡；超限将相应组报告为不可用。无需 root；实际读取权限不足时明确降级。

采集与发送由现有连接循环拥有，沿用单 reader / writer、64 KiB 消息和 5 秒写超时。ticker 合并未消费的 tick，没有指标发送队列或磁盘日志；断线后重新采样，不补发旧指标。任务回执仍使用原有持久化路径。采集只访问固定本地内核文件和 `/`；context 在读取前后检查，但不能抢占操作系统中已进入的文件或 statfs 系统调用。

## Panel 与界面

节点列表展示 CPU/内存，后台每 30 秒刷新当前已加载的节点；详情每 15 秒查询最新监控。`GET /api/v1/nodes/{id}/metrics` 需要 viewer 或以上会话，权限与当前实例节点列表一致。详情显示内存/Swap、磁盘、负载、运行时长及逐网卡速率与累计值。

Panel 按服务端接收时间每分钟保留最后一个采样点，最多 60 个点和最近一小时；这是分钟末采样，不是分钟均值。全局最多缓存 1024 个节点，超限淘汰最久未更新者。缓存仅在内存中，Panel 重启后重新积累，不用于计费或长期审计。历史只保存 CPU/内存使用率和网络速率合计；完整快照只保留最新一份。

采样时间必须在服务端时间前后 5 分钟内。每节点接收间隔不足 5 秒或采样时间未递增的快照被丢弃；原 WSS 消息速率限制仍生效。离线或超过 `max(90秒, 3 × 最近有效采样间隔)` 的快照标记过期，页面当前值显示未知并保留采样时间与历史。图表仅画最近一段连续有效数据，不将缺失点补零或跨断线连线。

## 兼容性

权威模型在 Panel `api/agent/v1/envelope.schema.json`。外层协议继续为 1.0，监控是显式版本化扩展 `node.metrics.v1`：

| Agent / Panel | 行为 |
| --- | --- |
| 旧 Agent / 新 Panel | 不发送新的 hello_ack 字段，不要求监控 |
| 新 Agent / 旧 Panel | 宣告监控能力；无 `metrics_version` 确认时不发送监控，原有节点检查可用 |
| 新 Agent / 新 Panel | 只有 Agent 宣告能力后，Panel 才回复 `metrics_version: 1` 并接受监控 |

旧版严格 JSON 解码器不会收到新的 ACK 字段。未协商的监控、跨节点报文、非法数值或错误结构拒绝并关闭连接。Schema、生成模型、样例和兼容测试一同维护；此工作区变更仍需随双仓库版本发布，不能视为已发布制品。

## 验证与边界

测试覆盖文件 fixture 的 CPU/网络差值、重置、采集失败恢复、读取上限、无权限等错误降级，真实 TLS/WSS 协商、旧版互通、任务共存、API 认证、跨节点拒绝、历史上限、过期和并发。Linux 下 `TestLiveLinuxMetrics` 额外读取真实 procfs；macOS 明确跳过此项，并验证不支持状态。

真实 Debian/Ubuntu/Alpine/NAT VPS 的运行、低配资源基准与长期压力仍需实机验收。当前不包含长期持久化监控、告警规则、代理用户流量、服务商配额、任意挂载点监控或容器配额视图。
